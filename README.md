# Omarchy & Hyprland Configuration

Personal Omarchy configuration files for Arch Linux + Hyprland.

## Structure

```
.config/
├── hypr/          # Hyprland window manager & display configuration
├── omarchy/       # Omarchy shell (bar, widgets, menus)
├── alacritty/     # Alacritty terminal settings
├── ghostty/       # Ghostty terminal settings
├── kitty/         # Kitty terminal settings
├── foot/          # Foot terminal settings
└── btop/          # Resource monitor configuration
```

## Setup

Symlink or copy desired directories into `~/.config/`:

```bash
cp -r .config/* ~/.config/
```
